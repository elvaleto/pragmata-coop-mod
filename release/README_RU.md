# PRAGMATA Split Control (Версия 1.0.0)

REFramework-мод локального кооперативного взлома для PRAGMATA. Первый игрок управляет Hugh, второй отдельным контроллером решает головоломки Diana.

## Установка

1. Установить совместимые с PRAGMATA версии REFramework и REFramework.NET C# API.
2. Извлечь архив в корневую папку игры с сохранением структуры каталогов.
3. До запуска игры открыть `PragmataSplitControl_Config.exe`.
4. Назначить контроллеры для Игрока 1 и Игрока 2, затем сохранить конфигурацию.
5. Запустить игру.

При включенном отладочном HUD в игре отображается строка `INPUT SPLIT: native filter active (blocked N)`.

## Разделение ввода

`PragmataSplitControl_InputFilter.dll` перехватывает функции XInput игры до их обработки в RE Engine. PRAGMATA получает только контроллер Игрока 1, а мод считывает ввод Игрока 2 отдельно. В режиме клавиатуры и мыши XInput-слоты скрываются от управления Hugh.

## Управление Игрока 2 (Diana)

Во время активной мини-игры взлома:
- `Y` / `X` / `A` / `B` (или `▲` / `■` / `X` / `●`) — направление решения головоломки (вверх / влево / вниз / вправо).

Подавтоматический возврат управления: если второй контроллер отключается, управление взломом автоматически передается Игроку 1.

## Steam Input

- Для связки Xbox-контроллер + DualSense: если DualSense используется нативно с адаптивными триггерами, отключите Steam Input в свойствах игры.
- Для двух XInput-контроллеров или использования Steam Input: настройте соответствие слотов в `PragmataSplitControl_Config.exe`.

## Удаление мода

Удалите следующие файлы из папки игры:
- `PragmataSplitControl_Config.exe`
- `PragmataSplitControl_InputFilter.dll`
- `reframework/data/PragmataSplitControl.ini`
- `reframework/plugins/managed/PragmataSplitControl.dll`

Мод не изменяет игровые PAK-файлы или сохранения.
